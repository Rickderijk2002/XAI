## MAIN TEST TAKEAWAYS (SUMMARY)
- Giving users a 0-1 slider for validity is misleading, since the model outputs binary values for validity only.
- There is some possible confusion throughout the game regarding which CF is the "original" (shown in tasks 1-2) and which is the one chosen in task 3. Additionally, it is generally hard for users to remember the CF's after task 3 (including chosen and best objective CF).
- Having to control-enter or click outside the final text-box to open the "next" button is unintuitive.
- Step 4 shows an overwhelming amount of information.
- Step 4 implausibility score is slightly confusing, as users did not give a human estimate value for this metric but did for the other two (validity/plausibility).
